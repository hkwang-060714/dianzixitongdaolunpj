# 魔方绕柱小车

基于树莓派的视觉循迹与绕柱控制示例：摄像头识别彩色目标，结合编码器反馈和 PID/PD 控制调整小车电机速度。本项目供学习与参考，使用前请根据自己的硬件检查接线和参数。

## 项目结构

- `test0.py`：单文件示例，包含颜色识别、电机控制和编码器测速逻辑。
- 视觉线程：通过 OpenCV 在 HSV 色彩空间识别红、黄、绿目标，并传递目标位置与尺寸。
- 控制线程：根据目标位置与编码器反馈调整电机速度，包含针对不同目标颜色的控制逻辑。
- 编码器线程：读取左右轮编码器脉冲，更新速度反馈。

## 运行前准备

- 树莓派、摄像头、电机驱动、左右轮编码器及对应的 GPIO 接线；引脚定义见 `test0.py`。
- Python 环境中安装 `opencv-python`、`numpy`、`pigpio`，并确保 `pigpio` 守护进程可连接。
- 按实际硬件检查摄像头编号、GPIO 引脚、PWM 设置及控制参数，再运行 `python test0.py`。

代码依赖具体硬件与 OpenCV API 版本，未保证在其他设备或环境中直接运行；首次测试请做好电机安全防护。
